# Project Architecture Map

## v2/ (Chronicle Ledger v2 - AWS Zero to Shipped 2026)
Evidence-Grounded Requirement Verification & Submission Readiness Platform.

### v2/backend/
Python 3.12/3.13 FastAPI backend with Mangum AWS Lambda adapter.

- **`engine/rule_schema.py`**: Pydantic models for structured requirements (`NUMERIC_COMPARISON`, `PRESENCE_CHECK`, `BOOLEAN_ASSERTION`, `VERSION_CONSTRAINT`), evidence artifacts, citations, and cryptographic audit records.
- **`engine/deterministic_evaluator.py`**: Pure, sandboxed mathematical and logical AST proof evaluator with tolerance checks and readiness score rollup.
- **`services/ai_service.py`**: Amazon Bedrock client (Claude 3.5 Sonnet / Amazon Nova) for requirement parsing, evidence citation matching, and live telemetry tracking.
- **`services/provenance_service.py`**: Cryptographic SHA-256 fingerprinting and verbatim text citation span locators.
- **`services/storage_service.py`**: Dual-mode JSON file and AWS DynamoDB persistence layer.
- **`tests/test_evaluator.py`**: Unit tests verifying deterministic proof evaluations.
- **`tests/test_api.py`**: Integration tests verifying full end-to-end project and verification workflows.
- **`main.py`**: FastAPI application entrypoint and Lambda handler.

### v2/frontend/
React 19 + TypeScript + Vite web command center inheriting Version 1 signature design system and authentication flows.

- **`src/context/AuthContext.tsx`**: Manages Google Sign-In and Instant Guest Demo session persistence.
- **`src/components/LandingView.tsx`**: Matches Version 1 landing page with Google Sign-In button, Try Instant Demo, brand monogram, directive badges, and architecture matrix.
- **`src/components/JournalDashboard.tsx`**: Matches Version 1 dashboard with Hide Archive toggle, 2-column layout, search/filters, recent entries, multi-mode switcher (Verification & Readiness, DevLog, Reflection, Brainstorm, Summary, Freeform), LinkedIn update cards, and prompt composer.
- **`src/components/RequirementModal.tsx`**: Requirement ingestion modal with prefill for AWS Zero to Shipped 2026 guidelines.
- **`src/components/EvidenceModal.tsx`**: Evidence ingestion modal with live SHA-256 fingerprinting.
- **`src/components/DossierModal.tsx`**: Official compliance verification dossier modal with export options.
- **`src/components/TelemetryModal.tsx`**: Live AWS Bedrock and Agent Telemetry HUD.
- **`src/index.css`**: Master design tokens (#FDFDFD canvas, #111111 obsidian buttons, Inter/JetBrains Mono typography).

### v2/infrastructure/
AWS serverless deployment templates and automation scripts.

- **`template.yaml`**: AWS SAM template configuring Lambda (ARM64), API Gateway (HTTP API), DynamoDB tables, S3 evidence bucket, and IAM Bedrock execution policies.
- **`deploy-aws.ps1` / `deploy-aws.sh`**: One-command build and deploy automation scripts for AWS.
