# Project Architecture Map

Unified Chronicle Ledger platform integrating multi-turn Socratic reflection (Google Cloud / Gemini) and deterministic requirement verification (AWS / Bedrock).

---

## 1. Frontend & Application Layer (`app/`, `components/`, `lib/`)
Next.js 15 (App Router) + React 19 + Tailwind CSS 4 web command center.

### `app/`
- **`app/page.tsx`**: Primary entry point routing unauthenticated users to `LandingView` and authenticated sessions to `JournalDashboard`.
- **`app/layout.tsx`**: Root layout configuring Inter typography, metadata, and dark/light system styles.
- **`app/api/gemini/reflect/route.ts`**: Server-side API endpoint invoking Gemini 3.6 Flash with multi-model fallback resilience.

### `components/`
- **`landing-view.tsx`**: Landing page with brand monogram, Google Sign-In, Try Instant Demo, directive badges, and architecture matrix.
- **`journal-dashboard.tsx`**: Core workspace supporting 6 modes (`Verification & Readiness`, `DevLog`, `Reflection`, `Brainstorm`, `Summary`, `Freeform`), 2-column sidebar layout, search/filters, LinkedIn update cards, and deterministic AST verification cards.
- **`auth-provider.tsx`**: Context provider managing Firebase Google Sign-In and Demo session persistence.
- **`chronicle-logo.tsx`**: Signature interlocking C & L SVG monogram with cyan/teal glow.
- **`requirement-modal.tsx`**: Ingestion modal for challenge guidelines and rule extraction.
- **`evidence-modal.tsx`**: Ingestion modal for attaching evidence with live SHA-256 fingerprinting.
- **`dossier-modal.tsx`**: Official compliance verification dossier modal with Markdown and JSON export.
- **`telemetry-modal.tsx`**: Live AWS Bedrock and coding agent telemetry HUD.

### `lib/`
- **`types.ts`**: Core types for interactions, turns, dual-cognitive responses, and journal modes.
- **`verification-types.ts`**: Structured types for AST rules, evidence artifacts, citations, and telemetry.
- **`verification-api.ts`**: API client connecting to backend verification endpoints with fallback states.
- **`firestore-service.ts`**: User-isolated Firestore interaction persistence.
- **`gemini.ts`**: Client configuration for Gemini 3.6 Flash with multi-model fallback ladder.

---

## 2. Deterministic Verification Backend (`backend/`)
Python 3.12+ FastAPI application with Mangum AWS Lambda adapter.

- **`main.py`**: FastAPI application entrypoint and Lambda handler.
- **`requirements.txt`**: Production dependencies (FastAPI, Pydantic, Boto3, PyYAML, Mangum).
- **`engine/rule_schema.py`**: Pydantic models for structured requirements, rule definitions, and audit records.
- **`engine/deterministic_evaluator.py`**: Pure, sandboxed mathematical and logical AST evaluator with zero hallucination guarantee.
- **`services/ai_service.py`**: Amazon Bedrock client (Claude 3.5 Sonnet) for requirement extraction and citation matching with live telemetry.
- **`services/provenance_service.py`**: SHA-256 fingerprinting and verbatim text citation span locators.
- **`services/storage_service.py`**: Storage ledger for projects, evidence, and audit trails.
- **`tests/`**: Automated test suite (`test_api.py`, `test_evaluator.py`).

---

## 3. Serverless Infrastructure (`infrastructure/`)
AWS serverless deployment templates and automation scripts.

- **`template.yaml`**: AWS SAM template configuring Lambda (ARM64), API Gateway (HTTP API), DynamoDB tables, S3 evidence bucket, and IAM Bedrock execution policies.
- **`deploy-aws.ps1` / `deploy-aws.sh`**: One-command build and deploy automation scripts for AWS SAM.
